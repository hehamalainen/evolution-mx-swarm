\f0\fs24 \cf0  # Simple Counter API                                                    \
                                                                          \
  ## Overview                                                             \
  Build a REST API with FastAPI that manages a counter.                   \
                                                                          \
  ## Requirements                                                         \
  1. GET /counter - Returns current count                                 \
  2. POST /counter/increment - Increases count by 1                       \
  3. POST /counter/decrement - Decreases count by 1                       \
  4. POST /counter/reset - Resets count to 0                              \
                                                                          \
  ## Acceptance Criteria                                                  \
  - Counter starts at 0                                                   \
  - All endpoints return JSON                                             \
  - Include basic tests       }
